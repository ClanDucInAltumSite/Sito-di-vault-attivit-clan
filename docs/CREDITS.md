### Sostituzione delle fotografie
I capi clan possono sostituire qualsiasi foto posizionando un file JPEG con lo stesso nome (`home.jpg`, `giochi.jpg`, `bans.jpg`, `canti.jpg`, `calendario.jpg`) all'interno della cartella `assets/photos/`. Il file di configurazione unico è `src/lib/photos.ts`.
